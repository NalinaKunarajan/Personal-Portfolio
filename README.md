## GitHub upload

Upload the contents of this folder to the repository, keeping the `assets` folder and `profile.jpg` exactly as shown.

Then enable GitHub Pages from:
Repository → Settings → Pages → Deploy from branch → main → / (root)

If you already have an older version online, replace the old `index.html`, `style.css`, `script.js`, and `assets/profile.jpg` with these files.

The portfolio also includes responsive layout, professional navy/teal styling, smooth reveal animations, navigation, education, skills, activities, achievement and contact sections.
