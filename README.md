# Nalina Kunarajan — GitHub Portfolio

## Profile Photo — FIXED

The profile photo is placed directly in the same folder as `index.html`.
There is **NO `assets` folder**.

### Final structure

```text
Nalina_Kunarajan_GitHub_Portfolio_NO_ASSETS_FOLDER/
├── index.html
├── style.css
├── script.js
├── README.md
└── profile.jpg
```

The HTML uses:

`./profile.jpg`

This works on GitHub Pages because the image and `index.html` are in the same directory.

### Upload to GitHub

Upload all five files to the same repository/root location:

- index.html
- style.css
- script.js
- README.md
- profile.jpg

Do not put `profile.jpg` inside another folder and do not use a Windows `C:\Users\...` path.

GitHub is case-sensitive, so keep the filename exactly `profile.jpg`.
